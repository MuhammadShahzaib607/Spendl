# Spendl

A simple web application built to manage personal income and expenses efficiently.

## Description

I created Spendl to solve a personal struggle with tracking finances. This tool allows you to organize your money flow by creating specific years and months. It helps you see exactly where you are spending and how much you are earning without any complicated features.

## Tech Stack

* **Frontend:** React, Tailwind CSS, Framer Motion, React Icons
* **Backend:** Node.js, Express
* **Database:** MongoDB with Mongoose

## Core Features

* **Yearly Management:** Create folders for different years (e.g., 2026) to keep data separate.
* **Monthly Tracking:** Add months inside each year to store transaction history.
* **Automatic Totals:** Every month card shows the total income and expense for that month.
* **Yearly Overview:** The main year card displays the combined total of all months.
* **Detailed Records:** Click on any month to view a full list of transactions with dates and descriptions.

## Setup Instructions

The frontend and backend are both located in this single repository. Follow these steps to run it locally:

1. **Clone the repository**

```bash
https://github.com/MuhammadShahzaib607/Spendl.git
```

2. **Install dependencies**

```bash
npm install
```

3. **Start the application**

```bash
npm run dev
```
